simple3D is an abstraction of vulkan used in DiversityEngine.

the example projects for SDL2 and GLFW show how to create a basic 3D application using Simple3D

There is support for ImGui in the renderer.

The API is in active development and I plan to add these features in future:
- a job system
- dynamic rendergraphs
- mindless texture arrays


I will provide shader templates for how to write shaders eventually
